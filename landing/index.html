为多智能体工作流设计Designed for multi-agent workflows

规划、实现、审查、调试、QA——把一个任务拆给专门的子智能体并行推进，再合并成一份结果。可持久化的工作流支持分阶段执行与断点恢复，跑到一半不会前功尽弃。 Planner, worker, reviewer, debugger, QA — split one task across specialized subagents working in parallel, then merge the results. Durable workflows run in phases and recover from interruptions, so long runs never start over.

架构Architecture

同一个 agent，随处可用。 The same agent everywhere you build.

wuu 是一个 Go 核心加多个 Shell：桌面应用、CLI，以及未来的编辑器插件，共享同一套运行时、会话和配置。在一个地方开始，在另一个地方继续。 wuu is one Go core with many shells: the desktop app, the CLI, and future editor plugins share the same runtime, sessions, and config. Start in one place, continue in another.

快速开始Quick start

三分钟，跑通第一个任务。 Your first task, in three minutes.

1

安装Install

wuu 处于 pre-1.0 阶段，目前推荐用 Go 从源码安装。wuu is pre-1.0 — installing from source with Go is the reliable path today.

$ go install github.com/blueberrycongee/wuu/cmd/wuu@latest
2

配置你的模型Point it at your model

初始化后，在配置里填上你的 provider 与 API Key 环境变量——Anthropic 或任何 OpenAI 兼容端点。After init, set your provider and API-key env var in the config — Anthropic or any OpenAI-compatible endpoint.

$ wuu init $ export ANTHROPIC_API_KEY="..."
3

交给它一件事Hand it something real

从描述仓库开始，到修一个失败的测试，再到把整份计划书变成实现。Start with describing the repo, move on to fixing a failing test, then hand it a whole plan to implement.

$ wuu exec "describe this repo" $ wuu exec "fix the failing test" $ wuu exec --file plan.md "implement this plan" # 昨天的会话，今天接着聊pick up yesterday's session $ wuu exec resume --last "continue"
