从修一个失败的测试，到功能开发、重构和迁移——wuu 在你的本地仓库里读代码、改文件、跑命令、复盘失败，直到结果收敛。 From fixing a failing test to features, refactors, and migrations — wuu reads code, edits files, runs commands, and iterates on failures in your local repository until the work converges.

交给它，就能拿回结果Hand it a task, get back a result

「修一下这个失败的测试」——它自己找到相关文件、动手修改、跑测试、根据报错继续调，最后交回一份干净的 diff 和一句人话总结。报错截图、需求文档，直接扔给它当上下文。 "Fix the failing test" — it finds the relevant files, makes the change, runs the tests, iterates on the errors, and hands back a clean diff with a plain-language summary. Error screenshots and spec docs go straight in as context.

大任务，拆开并行做Big tasks, split and run in parallel

不用盯着一个 agent 慢慢磨。wuu 会把任务拆给几个子智能体同时推进——一个改代码、一个审查、一个补测试——最后合并成一份结果。跑到一半中断了，从断点接着来，不会前功尽弃。 No babysitting a single agent. wuu splits the task across subagents working at once — one editing, one reviewing, one adding tests — and merges the results. If a long run gets interrupted, it picks up from the checkpoint instead of starting over.

用法How you use it

你用界面，
agent 用接口。 A GUI for you.
An interface for agents.

wuu 是一个桌面应用——你在窗口里交代任务、看过程、审改动。同样的能力也通过接口暴露出来，给 CI 和其他 agent 调用。 wuu is a desktop app — you hand over tasks, watch the process, and review changes in a window. The same capabilities are also exposed through an interface for CI and other agents to call.

01

桌面应用——你的入口The desktop app — your way in

多标签会话、完整的过程记录、逐文件的改动审查，随时打断和追问。日常工作全部在这里完成。Tabbed sessions, full process logs, file-by-file change review — interrupt and follow up anytime. This is where all your day-to-day work happens.

02

wuu exec——给 agent 的接口wuu exec — the interface for agents

不是给人敲的命令，而是把 wuu 的能力暴露给程序：CI 流水线、review 机器人，甚至别的 agent（比如 Claude Code）都能调用它干活，输出是机器友好的 JSONL。Not a command for humans to type — it exposes wuu's capabilities to programs. CI pipelines, review bots, even other agents (like Claude Code) can put it to work, with machine-friendly JSONL output.

03

你的编辑器（在路上）Your editor (coming)

FAQ

你可能想问。 Questions you might have.

要花钱吗？Does it cost anything?

wuu 本身免费开源（MIT）。你只为自己调用的模型付费——用你已有的 API Key，账单直接来自模型提供商，没有订阅，也没有抽成。wuu itself is free and open source (MIT). You only pay for the model calls you make — with your own API key, billed directly by your provider. No subscription, no markup.

我的代码会被上传到哪里吗？Does my code get uploaded anywhere?

wuu 在你自己的机器上运行。代码只会发给你自己配置的模型提供商——和你亲自调 API 一模一样，中间没有任何别的服务器。wuu runs on your own machine. Your code only goes to the model provider you configured — exactly as if you called the API yourself. There is no server in between.

支持哪些模型？Which models does it support?

Anthropic 全系，以及任何 OpenAI 兼容端点：OpenAI、OpenRouter、one-api、本地网关等。在配置里改一行就能切换。All Anthropic models, plus any OpenAI-compatible endpoint: OpenAI, OpenRouter, one-api, local gateways, and more. Switching is a one-line config change.

和 Cursor、Claude Code 有什么区别？How is it different from Cursor or Claude Code?

最大的区别是完全开源和 BYOK：没有订阅费，不锁定某一家模型，代码可以自己审计。形态上它是一个独立的桌面应用，不依附于某个编辑器，多智能体编排和定时任务是内置的。The big differences are full open source and BYOK: no subscription, no lock-in to one model vendor, and code you can audit yourself. It's a standalone desktop app rather than an editor plugin, with multi-agent orchestration and scheduled tasks built in.

既然是桌面应用，为什么还有个 CLI？If it's a desktop app, why is there a CLI?

wuu exec 不是给人用的入口，而是给程序的接口：CI 流水线、review 机器人和其他 agent 通过它调用 wuu 的能力，输出是机器友好的 JSONL。人用桌面端就好。wuu exec isn't an entry point for humans — it's an interface for programs. CI pipelines, review bots, and other agents use it to call wuu's capabilities, with machine-friendly JSONL output. Humans should just use the desktop app.

它能记住我的项目和习惯吗？Does it remember my project and preferences?

能。会话可以随时恢复、从检查点 fork；持久记忆跨会话保留偏好和上下文；技能（skills）让它按你的方式做特定类型的工作。Yes. Sessions resume anytime and fork from checkpoints; persistent memory carries preferences and context across sessions; skills teach it to do specific kinds of work your way.

现在到什么阶段了？How mature is it?

pre-1.0（当前 v0.1.0），接口和桌面端行为还在演进，目前推荐从源码安装。遇到问题欢迎提 issue。Pre-1.0 (currently v0.1.0) — interfaces and desktop behavior are still evolving, and installing from source is recommended. If you hit rough edges, open an issue.
