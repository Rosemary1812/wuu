你可能想问 Questions you might have

要花钱吗？Does it cost anything?

wuu 开源免费（MIT）。你只为自己的模型用量付费，账单直连提供商——没有订阅、没有抽成。wuu is free and open source (MIT). You pay only for your own model usage, billed straight by the provider — no subscription, no markup.

我的代码会被上传到哪里吗？Does my code get uploaded anywhere?

不会。wuu 全程在本地跑，BYOK——代码只发给你配置的提供商，不经我们任何服务器。要查？代码全开源。No. wuu runs fully local with BYOK — your code only goes to the provider you configured, never through a server of ours. Want to check? It's all open source.

支持哪些模型？Which models does it support?

Anthropic 全系，加任何 OpenAI 兼容端点——OpenAI、OpenRouter、one-api、本地网关都行。改一行配置就切。All Anthropic models, plus any OpenAI-compatible endpoint — OpenAI, OpenRouter, one-api, local gateways. Switch with one line of config.

和 Cursor、Claude Code 有什么区别？How is it different from Cursor or Claude Code?

它们是单个 agent 助手；wuu 是一支能协作的 agent 队伍，在一个群聊工作台里干活。再加上开源 + BYOK：不锁死某一家模型，代码也能自己审。They're a single assistant; wuu is a team of agents collaborating in one group-chat workbench — plus it's open source and BYOK, so you're not locked into one model vendor and can audit the code yourself.

它能记住我的项目和习惯吗？Does it remember my project and preferences?

会。越用越懂你的项目和做事方式——像个越处越合拍的搭子。Yes — it picks up your project and the way you work, and gets sharper over time. Like a teammate who really gets you.

现在就能用吗？Can I use it today?

能，日常开发已经能交给它了。有问题欢迎提 issue，也欢迎 PR。Yes — it's ready for day-to-day dev work today. Issues and PRs welcome.
