wuu 在你的本地仓库里读代码、改文件、跑命令、审改动。Go 核心 + 桌面应用 + 可脚本化 CLI，内置多智能体编排，支持 Anthropic 和任何 OpenAI 兼容端点。 wuu reads code, edits files, runs commands, and reviews changes in your local repository. wuu exec 是非交互式入口：它自己读文件、跑测试、改代码、复盘失败，直到测试变绿。输出是流式 JSONL，脚本、CI、review 机器人和其他 agent 都能直接驱动它。 wuu exec is the non-interactive entrypoint: it reads files, runs tests, edits code, and iterates on failures until the tests go green. Output streams as JSONL, so scripts, CI, review bots, and other agents can drive it directly.

特性Features

编排能力是运行时的一部分，不是外挂。 Orchestration is part of the runtime, not bolted on.

单轮任务之外，wuu 能规划多步工作、委派子智能体、运行可持久化的工作流——这些都长在核心里。 Beyond single-turn tasks, wuu plans multi-step work, delegates to subagents, and runs durable workflows — all of it native to the core.

01

BYOK，不锁定BYOK, no lock-in

自带 API Key，支持 Anthropic 与任何 OpenAI 兼容端点——OpenAI、OpenRouter、one-api，或你机器上的本地网关。换模型只需改一行配置。Bring your own API key. Works with Anthropic and any OpenAI-compatible endpoint — OpenAI, OpenRouter, one-api, or a local gateway. Switching models is a one-line config change.

02

子智能体协作Subagent delegation

规划、实现、审查、调试、QA——把工作委派给专门的子智能体，并行或隔离地推进，而不是让一个上下文背下所有事。Planner, worker, reviewer, debugger, QA — delegate to specialized subagents that work in parallel or in isolation, instead of one context carrying everything.

03

可持久化工作流Durable workflows

分阶段的多步任务，支持派生 worker 与中断恢复；配合技能（skills）、持久记忆与定时任务，长期工作也能安放。Multi-step runs with phases, worker spawns, and recovery — alongside skills, persistent memory, and scheduled tasks, so long-running work has a home.

04

为脚本化而生Scriptable by design

wuu exec 输出流式 JSONL——CI 任务、review 机器人、甚至另一个 agent，都能编程式地驱动它。wuu exec streams JSONL — CI jobs, review bots, and even other agents can drive it programmatically.

05

会话可持久Sessions that persist

恢复之前的对话、列出历史、从任意检查点 fork。上下文跨会话保留，工作不必从头开始。Resume previous turns, list history, fork from any checkpoint. Context carries across sessions — work never starts from zero.

06

桌面应用Desktop app

交互式工作用桌面端，自动化用 CLI。同一个核心，两种手感——群组会话、成员面板与主题系统都在持续打磨中。The desktop app for interactive work, the CLI for automation. One core, two textures — with group threads, member panels, and a theming system under active polish.

快速开始Quick start

三分钟，跑通第一个任务。 Your first task, in three minutes.

1

安装Install

wuu 处于 pre-1.0 阶段，目前推荐用 Go 从源码安装。wuu is pre-1.0 — installing from source with Go is the reliable path today.

$ go install github.com/blueberrycongee/wuu/cmd/wuu@latest
2

配置你的模型Point it at your model

初始化后，在配置里填上你的 provider 与 API Key 环境变量——Anthropic 或任何 OpenAI 兼容端点。After init, set your provider and API-key env var in the config — Anthropic or any OpenAI-compatible endpoint.

$ wuu init $ export ANTHROPIC_API_KEY="..."
3

交给它一件事Hand it something real

从描述仓库开始，到修一个失败的测试，再到把整份 PDF 计划书变成实现。Start with describing the repo, move on to fixing a failing test, then hand it a whole PDF plan to implement.

$ wuu exec "describe this repo" $ wuu exec "fix the failing test" $ wuu exec --file plan.md "implement this plan" # 昨天的会话，今天接着聊pick up yesterday's session $ wuu exec resume --last "continue"
