# Automations

Automations 让 Wuu 按计划在指定工作区中执行一段任务说明。它适合定时检查、周期性汇总
和稍后执行的一次性任务，不是独立运行的云端定时服务。

## 新建自动化

1. 在桌面端添加并选中一个真实工作区。
2. 从侧边栏打开**自动化**。
3. 选择**新建自动化**，再选择任务要运行的工作区。
4. 填写名称和任务内容。
5. 设置执行方式、运行间隔和时区。
6. 选择**新建自动化**保存。新任务默认暂停，检查无误后再开启。

任务内容就是每次触发时交给 Agent 的提示。应明确写出范围、期望结果和验证方式，例如：

```text
检查这个工作区中过去一天新增的 TODO。按文件汇总，只报告仍未解决的项目；
不要修改文件。如果没有新增 TODO，直接说明没有变化。
```

## 设置时间

桌面端提供以下计划：

- 每 5、10、15 或 30 分钟；
- 每小时；
- 每天；
- 工作日；
- 每周；
- 自定义五段式 Cron 表达式。

时区会随任务保存。修改时区后，列表中的“下次执行”也会按新时区重新计算。

重复任务不会保证卡在整点启动。Wuu 会为它加入稳定的小幅延迟，以避免许多任务同时运行；
延迟最多为计划间隔的 10%，且不超过 15 分钟。一次性任务若刚好落在半点或整点，也可能
最多提前约 90 秒。

## 选择会话方式

### 每次新建会话

`新建会话`适合彼此独立的检查。每次触发都会在任务所属工作区中创建一个新的自动化
会话，便于单独查看结果。

### 继续指定会话

`继续指定会话`会把任务发到已有会话，需要填写该会话的 ID。它适合在同一上下文中
持续跟进，但也有两个限制：

- 会话必须仍然存在并能在当前 Wuu 数据中加载；
- 如果该会话正在运行别的回合，自动化消息会排队，而不是并行写入同一会话。

## 管理任务

自动化列表支持搜索以及“全部、已开启、已暂停”筛选。选择一个任务后，可以直接修改
名称、任务内容、计划、时区和会话方式，也可以暂停、恢复或删除它。

Wuu 最多保存 50 个自动化任务。删除任务不可撤销，但不会删除它已经创建的会话。

当前桌面页没有“立即运行”按钮，也不展示单独的自动化运行历史。`新建会话`的结果会
出现在普通会话列表中；`继续指定会话`的结果写入目标会话。

## 运行条件和生命周期

Automations 由本机正在运行的 Wuu core 调度。电脑休眠、桌面应用退出且没有其他 Wuu
core 进程运行时，任务不会在后台执行。

- 错过的一次性任务会在调度器下次启动时补执行一次；
- 重复任务不会逐次补跑错过的时间点，多个漏跑会合并为下一次到期执行；
- **重复任务创建 7 天后会自动到期并从列表移除。**需要继续运行时，请重新创建任务；
- 一次性任务执行后会从计划列表移除。

同一个任务的上一次运行尚未结束时，Wuu 不会不断叠加新执行：新会话模式会跳过重叠
触发；继续会话模式最多保留一个正在运行和一个排队执行，更多触发会跳过。

任务使用执行时的模型、工具和权限配置。即使计划本身已经保存，权限限制、网络状态、
模型额度或工作区缺失仍可能让一次执行失败。

## 排错

### 到点没有运行

确认 Wuu core 当时正在运行，任务没有暂停，工作区路径仍然存在，并检查时区和列表中的
下次执行时间。重复任务还可能处在计划抖动窗口内。

### 任务消失了

一次性任务运行后会移除；重复任务创建 7 天后会到期。这两种情况都属于当前生命周期
规则，不是列表加载失败。

### 继续会话失败

核对填写的是会话 ID 而不是标题，并确认会话没有被删除。若任务不依赖历史上下文，改用
`新建会话`通常更稳妥。

### 需要由 CI 或脚本触发

桌面计划任务适合本机定时执行。由外部调度器、CI 或其他 Agent 驱动时，使用
[`wuu exec`](exec.md)。
