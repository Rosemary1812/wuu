# 记忆

记忆用于保存跨会话仍有价值的个人偏好、反馈、参考信息和经验。它与某次会话历史不同，
也不应成为项目事实或临时任务日志的副本。

## 查看记忆

打开**设置 → 记忆**，或者在输入框中使用 `/memory`。面板提供：

- 根据真实笔记本生成的概览；
- 刷新概览；
- 查看 `MEMORY.md` 索引和记忆文件原文；
- 用对话方式要求添加、修正或删除记忆，并查看实际变更文件。

概览会缓存一段时间；需要立即反映原文变化时使用刷新。概览由当前模型生成，原文视图
才是审计记忆内容的直接依据。

## 适合保存什么

- 长期沟通偏好；
- 用户明确给出的工作反馈；
- 跨项目仍成立的参考入口；
- 以后遇到类似问题仍有用的经验。

不要保存密钥、原始对话、短期任务进度、提交 SHA、一次性日志，或可以直接从当前仓库
重新获得的事实。

## 数据和模型调用

用户记忆默认位于 `~/.wuu` 下的记忆目录；设置 `WUU_HOME` 会整体移动 wuu 的用户
状态。生成概览和通过对话修改记忆会调用当前模型服务，原文读取不需要模型。

记忆可能作为相关上下文发送给模型。处理敏感内容前，请同时检查记忆原文、模型服务的
数据政策和[安全模型](../reference/security-model.md)。
