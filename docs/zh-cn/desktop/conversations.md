# 会话与分支

会话保存你与 Agent 的消息、工具活动和任务上下文。项目文件是最终成果，会话则让你能
继续、检查或从较早位置尝试另一条路径。

## 新建和继续会话

- 使用侧边栏的**新对话**在当前工作区开始任务。
- 重新打开已有会话即可继续，不必在每条消息里重复项目背景。
- 可以搜索、重命名、置顶或归档会话。

归档只会把会话从默认列表隐藏；在**设置 → 归档**中可以筛选和恢复。删除会移除保存的
历史及 wuu 能定位到的会话产物，应只在确定不再需要时使用。

## 任务运行时

消息流会显示工具调用、后台命令和子任务状态。主 Agent 正在处理当前轮次时，可以直接在
输入框中补充消息：

- **Enter：发送引导。** 消息加入当前轮次，用于补充信息、缩小范围或调整后续方向。
- **Tab：排队发送。** 消息在当前轮次结束后作为下一条用户消息处理。
- **Shift + Enter：换行。**

只要子代理仍在运行，当前轮次和会话就仍是运行中。此时 Enter 仍会把消息作为引导加入
当前轮次，主 Agent 会结合新要求继续协调；Tab 则把消息排到这次协作全部结束之后。
输入框没有内容或任务没有运行时，Tab 保持普通的焦点切换功能。

发送引导不会撤销已经执行的命令或文件改动。发现方向明显错误时，优先用 Enter 补充范围
或约束。停止当前回复会冻结或取消正在运行的匿名 worker 树，并清除尚未启动的排队任务；
这些工作不会在下一条消息中自动恢复。工具活动能帮助理解过程，但最终仍应检查文件、diff
和验证结果。

复杂任务中，主 Agent 可能把独立调查、实现或复核交给子代理，并在收到结果后继续整合。
它与后台命令、定时自动化的区别见[Agent 协作与子代理](subagents.md)。

## 从较早消息分叉

在历史消息上选择**分叉**，可以从那个时间点创建新会话：

- **派生到本地：**在当前本地文件状态下创建新的聊天分支；
- **派生到 git worktree：**为 Git 项目创建独立 worktree，再从分叉点继续。

会话历史可以回到较早消息，但磁盘文件不会自动回到当时状态。如果后续轮次已经修改了
文件，新的本地分支可能与历史消息中的状态不一致；需要文件隔离时优先使用 worktree。

## 侧聊

侧聊用于询问当前任务而不把内容加入主对话，例如解释一段输出或比较两个方案。它不是
新的项目分支，也不会替代需要长期保留的主会话。当前 runtime 不支持时，界面会把入口
标记为不可用。

## CLI 中的会话

```bash
wuu session list
wuu session show --last
wuu session search "关键词"
wuu exec --continue "继续最近的会话"
wuu exec resume THREAD_ID "继续这个任务"
```

自动化任务不需要保存会话时使用 `wuu exec --ephemeral`。完整选项见
[中文 `wuu exec` 指南](../automation/exec.md)。
