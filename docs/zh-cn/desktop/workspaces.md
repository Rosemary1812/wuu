# 工作区与项目

工作区决定 wuu 能直接操作哪些本地文件、命令在哪个目录运行，以及会话在侧边栏中的
归属。开始文件任务前，先确认当前工作区比调整提示词更重要。

## “对话”和真实项目

桌面端有两类入口：

- **对话：**不绑定真实目录的共享区域，适合一般问答。它会保存会话，但不代表某个
  项目文件夹。
- **项目：**绑定你选择的本地目录，适合阅读和修改文件、运行命令、检查 Git 改动。

如果回答里出现了错误的目录、技术栈或历史会话，先停止任务并检查当前项目。

## 添加工作区

在左侧栏的**工作区**区域选择**添加工作区**：

- **使用现有文件夹：**登记已有项目目录；
- **新建空白项目：**创建并登记一个新的空目录。

添加工作区不会把项目上传到 wuu。文件仍保存在原位置；与模型交互时，只有任务需要的
提示词、文件内容和工具结果会发送给当前模型服务。

## 切换和整理项目

- 选择项目名称可进入它的工作区，并查看归属于该项目的会话。
- 可以折叠、排序项目区域，也可以把常用会话置顶。
- 从侧边栏移除项目只会移除 wuu 的登记，不会删除磁盘上的项目文件；已有会话仍保存在
  本地状态中。
- 如果目录被移动或改名，项目会显示为不可用。使用**重新定位**选择新目录，可以保留
  原项目身份和会话归属。

## 工作区边界

默认的 `standard` 权限模式把文件工具限制在已登记的工作区根目录内，但它不是操作
系统沙箱。获准运行的命令仍以当前登录用户身份执行。处理不可信仓库或敏感资料前，
阅读[权限模式](../reference/permissions.md)和[安全模型](../reference/security-model.md)。
